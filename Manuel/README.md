# Manuel simManquant — version révisée

Ce dossier est un projet Quarto complet. Les fichiers ont été normalisés selon les
noms attendus par `_quarto.yml` afin d'éviter les suffixes ajoutés lors du dépôt des
pièces jointes.

## Compiler

Dans RStudio, ouvrez le dossier puis rendez le projet Quarto; ou, dans un terminal :

```bash
quarto render
```

Les sorties sont écrites dans `_book/`. Le projet produit les formats HTML, PDF et
EPUB lorsque les dépendances Quarto et LaTeX requises sont disponibles.

## Contenu de la révision

- guides « Lire l'écran » pour interpréter les sorties de l'application;
- formulation méthodologique nuancée sur MCAR, MAR, MNAR, cas complets, imputation
  multiple et FIML;
- page de références corrigée et bibliographie APA incluse;
- configuration PDF de la couverture corrigée.
